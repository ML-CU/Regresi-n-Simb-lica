# 📌 Regresión Simbólica Aplicada a una Fintech

Este proyecto explora el uso de **Regresión Simbólica** como técnica de *IA explicable* para modelar y comprender el comportamiento financiero de los usuarios de una Fintech.  
A diferencia de los modelos tradicionales, la regresión simbólica genera **ecuaciones matemáticas explícitas**, fáciles de interpretar por equipos técnicos y de negocio.

---

## 🚀 Objetivos del Proyecto

- Simular o cargar datos del comportamiento de clientes de una Fintech.
- Entrenar un modelo de regresión simbólica usando `gplearn`.
- Obtener una **ecuación interpretable** que explique el flujo monetario de los usuarios.
- Analizar el comportamiento del modelo y su significado en un contexto financiero.
- Visualizar resultados y compararlos con los valores reales.

---

## 🧠 ¿Qué es la Regresión Simbólica?

La **Regresión Simbólica** busca encontrar la *mejor ecuación matemática* que relacione una variable objetivo con sus variables explicativas. Lo hace mediante programación genética.

A diferencia de modelos tipo *caja negra*, aquí la salida es una **fórmula clara**.

## 📝 Resultados Principales

- Se obtuvo una **ecuación interpretable** que modela el flujo de dinero de usuarios.
- El modelo identificó patrones clave asociados a:
  - Número de transacciones.
  - Monto promedio.
  - Frecuencia de recargas.
  - Uso de promociones.

Esto permite comprender *por qué* un usuario incrementa o reduce su actividad, no solo predecirla.
