📘 Proyecto de Regresión Simbólica

Este repositorio contiene el desarrollo de un modelo de Regresión Simbólica en Python, cuyo objetivo es descubrir fórmulas matemáticas que describen relaciones entre variables a partir de datos.

A diferencia de los modelos de regresión tradicionales, la regresión simbólica no se restringe a una estructura fija, sino que genera expresiones matemáticas interpretables combinando operadores y funciones, lo que permite encontrar patrones ocultos y fórmulas similares a las que usaría un científico o ingeniero.

📂 Contenido del proyecto

Exploración de datos: análisis inicial de los conjuntos de datos.

Implementación del modelo: uso de librerías de Python como gplearn y sympy para realizar regresión simbólica.

Evaluación de resultados: comparación con modelos de regresión lineal y polinómica.

Visualización: gráficas de predicciones vs. valores reales y representación de las ecuaciones encontradas.
